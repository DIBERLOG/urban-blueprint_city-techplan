Политика конфиденциальности

Настоящая Политика определяет порядок обработки и защиты персональных данных пользователей сайта urban.diberlog.ru — браузерный редактор 2D-схем города: зоны, дороги, здания, версии и экспорт.

1. Оператор

Оператор персональных данных: физическое лицо Ангелов Егор Алексеевич, адрес: Российская Федерация, г. Москва, ул. Чугунные Ворота, д. 3, к. 1, кв. 59, email: workbook.ea@mail.ru.

Связаться с оператором можно по почте workbook.ea@mail.ru.

2. Какие данные обрабатываются

На сайте нет форм обратной связи и регистрации. Сайт не собирает имена, адреса электронной почты и иные данные, которые вы вводите, — работа в редакторе остаётся в вашем браузере.

Веб-сервер ведёт технические журналы запросов: IP-адрес, дата и время, адрес запрошенной страницы, источник перехода и сведения о браузере. Журналы нужны для работы и защиты сайта, хранятся на том же сервере и удаляются автоматически по мере обновления (не более пяти файлов по 10 МБ).

Оператор не запрашивает специальные категории персональных данных, биометрические и паспортные данные, платёжные данные и сведения о здоровье. Не направляйте такие данные через сайт.

3. Цели обработки

Обеспечение работы и безопасности сайта, диагностика технических проблем.

4. Правовые основания

Обработка технических данных журналов необходима для работы сайта, который пользователь открывает по собственной инициативе.

5. Передача данных

Для работы сайта используются: хостинг-провайдер FirstVDS (размещение сайта и сервера). Эти сервисы получают данные только в объёме, необходимом для своей задачи.

Сайт не загружает файлы со сторонних ресурсов, кроме собственных.

Оператор не продаёт персональные данные, не передаёт их для рекламы и не публикует обращения.

6. Трансграничная передача

Серверы сторонних ресурсов, с которых загружаются файлы страниц, могут находиться за пределами Российской Федерации; им передаются только технические данные браузера.

7. Сроки хранения

Технические журналы удаляются автоматически по мере обновления. Данные в браузере (см. Политику cookies) хранятся, пока вы их не удалите.

8. Права пользователя

Вы вправе получить сведения об обработке своих данных, потребовать их уточнения, блокирования или удаления и обратиться к оператору по любому вопросу обработки данных. Для этого напишите на workbook.ea@mail.ru.

9. Несовершеннолетние

Сайт может быть интересен школьникам и студентам. Если пользователь не достиг возраста, с которого он вправе самостоятельно давать согласие на обработку персональных данных, отправлять обращения можно с согласия родителя или законного представителя.

10. Защита данных

Сайт работает только по защищённому соединению HTTPS. Сервер настроен так, чтобы доступ к нему был только у оператора.

11. Cookies и данные в браузере

Какие данные сайт хранит в вашем браузере, описано в Политике cookies.

12. Изменение Политики

Оператор обновляет Политику при изменении сайта, состава данных, используемых сервисов или требований закона. Действующая редакция всегда размещена на этой странице.
